## Task 1 — Rewrite the value tables in `boost-control.md` and `knock.md`

These two docs predate the rule that the definition XMLs are ground truth. They
quote stock values as if current and misname several constants.

### Start here

```
python scripts/doc_value_check.py --rev 20.19c
```

It should print 8 `STOCK` and 2 `NO-MATCH`. When Task 1 is done it should print
0 `STOCK`. The one remaining `NO-MATCH` (tip-in memory note, `0xCD0D8`, "16") is
a false alarm: 16 is a count of breakpoints.

### What to fix

**`docs/boost-control.md`, "PID terms"**

- `0xC0D04`, `0xC0D3C`, `0xC0D74` are NOT gains. The definition XML names each as
  the "Boost Error" axis of Turbo Dynamics Proportional (`0xC0D28`), Integral
  Negative (`0xC0D60`) and Integral Positive (`0xC0D98`). Replace the three rows
  with the tables themselves, read through `scripts/defs.py`.
- Remove "Derivative (disabled)". There is no derivative term.
- Remove "Task 52's IIR filter uses `0xC0D74 = 0.5`". That address reads 0.0 in
  every rev. Whether Task 52 has a filter coefficient somewhere else was NOT
  checked; do not replace the sentence with a guess.
- `0xC0BD4` TD Activation Thresholds (Target Boost): doc 210, car 12 psi display
  (raw 620.58). `0xC0BDC` TD Integral Negative Activation: doc 0.0, car 0.1 psi
  display (raw 5.17).

**`docs/boost-control.md`, "Safety / disable conditions"**

- `0xC0BFC` Boost Control Disable (IAM): doc 0.2, car **0.5**.
- `0xC0BF8` Boost Control Disable (Fine Correction): doc −1.0, car **−2.0**.

**`docs/boost-control.md`, "Enable hysteresis"**

- Direction is reversed. At `0x05488C`–`0x0548A6`, `byte[gbr+128]` is SET when
  the value is ≤ `[0xD6720]` (4.0) and CLEARED when it is > `[0xD6724]` (5.0).
- NOT decoded: whether a set flag means enabled or inhibited, and whether the
  value compared is engine load. Decode the function before rewriting.

**`docs/knock.md`, "Key constants"**

- `0xD2F48` is Fine Correction **Advance** Value (0.25 on the car), not the
  retard step. The retard step is `0xD2F50` Fine Correction Retard Value (1.01).
- `0xD2F4C` Fine Correction Retard Limit: doc −11.75, car **−15.0**.
- `0xD29EE` Fine Correction Advance Delay: doc 125, car **90**.
- `0xD2F44` is Fine Correction Advance Limit (8.0), which matches the doc.
- NOT checked: the doc's descriptions of `0xD2F40`, `0xD2F54`, `0xD2F58`. They
  have no definition name. The blind reader disputed all three; decode before
  keeping or changing them.

**`docs/knock.md`, "Pipeline"** — disputed, not settled. `0x4438C`, `0x43D68`,
`0x45BFE`, `0x463BA` have their addresses stored together in a pointer list at
`0x04AD6C`–`0x04ADA4`, and the code around `0x45BFE` loads `0xFFFF3234` (IAM).
That fits "IAM learning, called from a list" better than the doc's "per-event
retard path in an event-driven chain". Decode before rewriting.

**`docs/knock.md`, "Sign convention"** (`0x73600`) — disputed, not checked at all.
