SUMMARY

  [0xFFFF7B38] is 1 it runs two accumulators A and B (each: increment = product of two table lookups,
  candidate = clamp(acc + increment [x gain], -1, 1), then an anti-windup update against the previous
  output), a ramp factor, and an output X_OUT [0xFFFF7AF4] = clamp(A_ACC + B_ACC [x RAMP when the previous
  output was negative], LO, HI) with LO / HI from four more lookups.  When EN != 1 it zeroes both
  accumulators and steps X_OUT toward 0.0 (dead band, then calibrated steps floored / capped at +0.0;
  X_OUT cannot change sign on this path when the dead-band width K380 >= 0, as shipped (0.0); with
  K380 < 0 it can -- MECHANISM, OUTPUT).
  When byte [0xFFFF67FC] == 1 X_OUT is forced to +0.0.
