================================================================================
FINAL TIMING SUM, AND THE REQUEST-DRIVEN RETARD CHANNEL 0xFFFF803C
Traced 2026-11-25.  Reference bin: rom/AE5L600L 20g rev 20.19e.bin
Every table and constant below is byte-identical to stock rom/ae5l600l.bin.
Decoder: scripts/sh2e_disasm.py (displacements below are already in bytes).
================================================================================

WHY
--------------------------------------------------------------------------------
Logs show single-sample timing stabs (4-11 deg against ~17-20 settled) after a
gear change, on the rpm upswings of a ~6 Hz oscillation, with fuel on. The
question was which routine produces them. This trace decodes the sum that
builds total timing, rules two channels out, and decodes the one channel that
fits. It does NOT prove that channel fires on this car: its input arrives over
CAN and cannot be settled from ROM bytes.

HEADLINE
--------------------------------------------------------------------------------
1. Total timing is a straight sum when byte [0xD2976] == 90 (it is 90, stock
   and 19e). The sum at 0x03F618-0x03F674 adds or subtracts sixteen terms.
   Three are retard channels of interest:
     [0xFFFF8028]  added       overrun retard, function 0x041BE4 (items 74/79/103)
     [0xFFFF803C]  added       request-driven retard, function 0x041E00 (this file)
     [0xFFFF8000]  subtracted  cold-engine retard, function ~0x0415B8
2. 0x041E00 writes [0xFFFF803C]. While byte [0xFFFF5DD8] == 1 and float
   [0xFFFF5E64] >= 1.0 it applies descriptor 0xADE1C indexed by [0xFFFF5E64]:
     input   0     1.96    3.92    5.88    7.84   25.1   100
     retard  0    -4.92   -9.84  -15.12  -20.04    0      0
   then recovers at +1.05 deg per call above 800 rpm (descriptor 0xADE30).
   A continuous request is cut off after 125 calls (uint16 [0xD29CC]).
3. [0xFFFF5E64] is byte 1 of received CAN frame 0x421, scaled 100/255
   (unpack at 0x016928-0x016940, message table 0x063690). So this channel is
   an ignition retard requested by another module on the bus.
4. No definition XML covers 0xADE1C, 0xADE30, 0xD29CC or 0xD2983.

RULED OUT FOR THE WARM POST-SHIFT STABS
--------------------------------------------------------------------------------
[0xFFFF8000]: every table its writer reads on the ECT axis is 0 at 70 degC and
above (descriptors 0xAE46C, 0xAE450; 0xAE4A4, 0xAE4F8, 0xAE4C0 are all zero).
At 20-50 degC, load 0.52, 0xAE46C holds 20.04 deg, so it matters cold, not warm.
[0xFFFF8028]: OBSERVED in logs/11-24 20.19e, 1-2 shift at t=438.0-438.5 s:
Timing reads 24.5, 23.0, 21.5, 20.0, 20.0, 20.0 while IPW = 0, i.e. the overrun
retard never armed during the short cut, so there is nothing to ramp out, and
re-arming needs the previous pass's tier byte to be 4.
