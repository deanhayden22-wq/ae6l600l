ANSWER
--------------------------------------------------------------------------------
`0xAB03C` is a 2-D uint8 surface, **31 throttle-angle rows x 15 RPM columns**,
scale 0.39215684, values 0..100. It is the **expected manifold pressure** term of
an OBD-II MAP-sensor rationality monitor. It is a DIAGNOSTIC. It is not a lever.

It was flagged as "the single most interesting unexamined table in the ROM"
because its consumer touches `manifold_pressure_map` and the triage's RAM
signature therefore called it boost/MAP. **The GBR-base signal called it
ADC / I-O, and the GBR signal was right.** Recorded because the disagreement is
the useful part -- see docs/analysis-plan.md.

THE SIBLING
--------------------------------------------------------------------------------
`0xAAF84`, 1-D uint16 x15 on the same RPM axis, data 13.64 -> 57.30. It is the
minimum-throttle enable threshold, and its units match `0xAB03C`'s 31-value row
axis (10.58 .. 83.90) -- which is what confirms that axis is throttle angle.

NOT IN THE XML
--------------------------------------------------------------------------------

`address=` entry in the project XML.

WHAT THIS DOES NOT ESTABLISH

* `0xFFFF2240` and `fn_0x29AA0` are not decoded here.
* Nothing is NAMED. The reading above is what the code does; the label is not
