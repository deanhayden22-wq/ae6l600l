Notation        u8 / s8 / u16 / s16 / u32 / f32[ADDR] = big-endian access at ADDR; s8 and s16 are sign-extended
                (every mov.b / mov.w LOAD sign-extends; a byte / word STORE keeps the low 8 / 16 bits).
                f32@ADDR = the float32 constant stored in ROM at ADDR (a mova target).
                sat8(v)  = clamp(trunc(v + 0.5), 0, 255)    -- 0x0BE5A8 with v = (fr4 - fr6) / fr5
                sat16(v) = clamp(trunc(v + 0.5), 0, 65535)  -- 0x0BE5D8, same arguments
                "tail-call G": G is entered with the PR the member itself was entered with and r15 as on entry,
                so G returns wherever the member would have (jmp / bra after lds.l @r15+,pr, or with PR never
                saved).  For a member reached by jsr / bsr that is its caller's return address.  The eleven
                interrupt-handler classes are NOT entered that way: their stub jumps in with PR = 0x002BD4, so
                their G returns to 0x002BD4, not into the stub (INTERRUPT ENTRY, below).
                "call F": F returns into the member (jsr / bsr).
