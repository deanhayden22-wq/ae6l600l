EFFECTIVE BEHAVIOUR WITH THE 20.19c (= stock) CALIBRATION  (arithmetic from the tables above; emu P6)
  * M = 1.0, so O1 = clamp(A*aL*aE + C*cL*cE, -0.0999756, +0.0999756) and
    O2 = clamp(B*bL*bE + D*dL*dE, -0.0999756, 0.0).
  * seedB is all zero and bL = bE = 1: B is 0 after any main-path call that starts from B = 0, so the
    B term contributes nothing; EVENT 5 in effect only zeroes A, C and D.
  * The bit5 and bit3 thresholds are identical (80.0 / 79.5): for a byte whose bit5 and bit3 agree, EVENT 5
    and EVENT 3 fire on the same call, leaving A = C = 0 and D = seedD(X0).
  * aE is 0 for E <= 40 and 1 for E >= 60: the A term is absent at E <= 40.
  * hi2 = 0.0: O2 can never be positive; seedD <= 0 and D only moves toward 0, so the clamp does not bind
    from a reset start.
  * REACHABLE RANGE OF S. Every value A, C, D can hold is a seed or a step of a seed toward zero (dec()
    never increases |v|; the only other writer, 0x0392C4, writes 0.0), so from a zeroed block A <= 0,
    C >= 0, D <= 0, B = 0. With the table maxima: 0 <= C*cL*cE <= 0.0234375 * 1.0 * 2.0 = 0.046875,
    -0.0352 <= A*aL*aE <= 0, -0.046875 <= D*dL*dE <= 0. Hence S <= +0.046875 always, and the +0.0999756
    upper clamp of O1 cannot be reached from finite inputs (a NaN product gives the LOWER clamp). S >=
    -0.046875 while bit5 and bit3 of each byte agree (EVENT 5 then zeroes A whenever EVENT 3 seeds D);
    -0.0820 is the table bound otherwise. emu P11: 864 event calls over an X0 x E x L grid give max S =
    +0.0468750 (X0 700, E -50, L 0.7) and min S = -0.0468750; a 60-call run with repeated edges at the
    maximising point never exceeds it. (Premise: the block starts from zeros -- the reset path or
    zero-initialised RAM; the power-up RAM state is not established here. The lower bounds also assume a
    finite P and Q: a NaN or infinite P or Q makes M NaN and gives S = lo1 + lo2 = -0.1999512 on every
